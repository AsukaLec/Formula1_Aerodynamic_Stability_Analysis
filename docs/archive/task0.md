# 课题需求文档 (task.md)

## 1. 项目概览
* **题目：** 基于粒子群算法的F1赛车气动参数寻优方法的研究
* **课程：** 《计算智能》课程设计开题报告
* **数据集：** F1 Aerodynamic Stability and Porpoising (150k Samples)
    * *链接：* [Kaggle Dataset](https://www.kaggle.com/datasets/igormerlinicomposer/f1-aerodynamic-stability-and-porpoising-150k-samp/data)
* **核心痛点：** 1. 体育规则限制了CFD仿真资源（ATR限制），需要轻量化代理模型。
    2. “海豚跳”瞬态非线性气动特性难以捕捉。
    3. 数据集因变量（Stability Index, 0-100）极度不平衡：>90的样本占绝大多数。

## 2. 功能需求详解

### 阶段一：数据预处理与特征工程
* **输入：** Kaggle原始150k数据集。
* **任务：**
    * **常规处理：** 异常值清洗、Min-Max归一化（针对不同变量量级）。
    * **关键处理 (不平衡)：** 标记低分样本(<90)和高分样本(>=90)，作为后续损失函数加权或采样依据。
    * **特征挖掘：** 1. 执行特征间的相关性分析。
        2. 根据实际的气动稳定性，对关键参数（如前翼角度、时速）进行离散的聚类分层。
        3. 构建物理复合特征（例如：`speed_kmh * downforce_n`, `force_ratio = downforce_n / drag_n`）。
* **输出：** 经过增强和均衡化预处理的预训练数据集。

### 阶段二：数据可视化分析 (EDA)
* **任务：** 1. 绘制稳定性指标 (Stability Index) 的分布直方图，量化其偏态程度。
    2. 绘制自变量两两之间以及自变量与因变量之间的交互散点图。
    3. 特别关注 DRS状态 (drs_active)、前翼角度 (wing_angle_deg) 与稳定性之间的非线性关系区域。
* **输出：** 一系列直观的可视化图表，揭示数据分布规律。

### 阶段三：基准预测模型建立 (代理模型)
* **任务：**
    * **核心路径：** 构建多层感知器 (MLP) 结构的 BP神经网络。
        1. 针对数据不平衡，设计自定义损失函数，增加对低分样本拟合错误的惩罚权重。
        2. 在全数据样本上进行深度学习训练，捕捉非线性映射关系。
    * **备选路径 (风险应对)：** 构建基于 XGBoost 的基准模型。
        1. 利用数据预处理阶段的离散化特征，提升决策树对阈值效应（阶跃变化）的捕捉精度。
* **预期指标：** 决定系数 (R²) ≥ 0.90，均方误差 (MSE) ≤ 0.05（全样本及低分样本区域独立验证）。
* **输出：** 训练完毕并经过验证的高保真“虚拟风洞”BP模型 (及XGBoost模型文件)。

### 阶段四：代理模型物理合理性验证 (补充)
* **任务：** 1. 利用训练好的基模型，选择具有代表性的工程工况（如高速直道、中速弯道）。
    2. 生成全局或局部响应面三维图（例如：固定DRS开启，绘制（速度，前翼角度）到（稳定性指标）的曲面）。
    3. 人工验证曲面是否符合基本气动物理常识，确保PSO算法在物理正确的曲面上工作。
* **输出：** 工程工况下的响应面可视化图表。

### 阶段五：粒子群算法设计与特化改进
* **任务：**
    * **核心路径：** 搭建基于神经网络适应度的 PSO 寻优框架。
    * **核心特化：** 1. 重新设计**适应度函数 (Fitness Function)**：将神经网络预测值作为主分，并引入惩罚项。对粒子群探索到特定低分样本聚集区或极端物理边界区（超高速低翼角）进行加权惩罚，迫使算法谨慎探索不稳定区域。
        2. 引入**非线性自适应惯性权重**策略：寻优初期使用较大惯性进行全局探测，随迭代代数动态衰减以进行精细化局部收敛。
* **输出：** 经过针对不平衡数据进行适应度优化的 PSO-BP 寻优模型。

### 阶段六：多场景场景寻优及决策支持
* **任务：**
    1. **场景定义：** 定义典型F1赛道工况。
        * **高速赛道（如Monza）：** 高时速 (e.g., 300km/h), 小前翼角度, 强制约束最优化稳定性。
        * **高下压力赛道（如Monaco）：** 中低速 (e.g., 180km/h), 大前翼角度, DRS不开启, 在下压力>某一阈值的前提下，最优化稳定性。
    2. **寻优求解：** 粒子在由物理规则定义的自变量多维参数空间内进行演进寻找最优自变量调校方案。
* **预期指标：** 收敛代数 ≤ 50 代，单次寻优平均耗时 ≤ 5 秒。
* **输出：** 不同场景约束下的最优自变量调校组合（最优自变量调校族图谱）。

### 阶段七：实验结果对比与分析
* **任务：**
    1. 统计PSO融合模型与传统优化方法（如多元线性回归寻优对照组）在寻优收敛率、最优解标准差及单次耗时方面的增益。
    2. 整理实验数据，绘制对比图表，如收敛曲线图、参数演进路径图。
    3. 整理代码仓库、可视化图表和最终结题报告。
* **输出：** 完整的实验对比结论和可运行的代码。
