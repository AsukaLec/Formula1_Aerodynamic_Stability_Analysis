**问题**: XGBoost 同源数据解释了 XGBoost 精度，但 Random Forest 也达到 R²=1.0 需要独立解释。

**文件**: `04_surrogate.tex:169-171`

**新增**: 
```
Random Forest达到近乎完美精度表明该数据生成机制具有较强的结构规律性——
即便采用与生成器不同的模型架构（RF基于Bagging和随机子空间），
只要模型容量足够，即可近乎零误差地复现生成规则。
这进一步说明代理模型性能已接近该数据集可达到的信息上限。
```

### Issue 4+7: 结论应强调"数据结构决定优化上限"

**问题**: 全报告最有价值的发现（所有算法结果趋于一致，drag→18, wing→20 反复出现）在结论中层次不够高。

**文件**: `10_conclusion.tex:5-7` (导言段落)

**修改前**: `构建了一套完整的数据驱动代理优化框架。主要贡献可以概括为以下五个方面：`

**修改后**: `研究的过程本身揭示了一个比PSO寻优性能更重要的发现：代理模型驱动优化的效果上限并非由优化器决定，而是由数据结构和目标函数设计共同约束。以下从五个技术贡献和一个核心科学发现两个层面总结本研究的成果。`

**文件**: `01_abstract.tex` (摘要结论段)

**修改后**: 追加"本研究的核心发现是：在数据驱动的优化中，优化器选择的影响远小于数据分布结构本身——当86%的样本趋近饱和时，PSO、GA、DE的结果趋于一致，优化景观而非优化算法决定了寻优上限。"

### Issue 5: PSO 轨迹覆盖 ≠ 完整目标空间

**问题**: 6.4 节展示的点来自 PSO 搜索轨迹而非全空间采样，经验前沿面不可等同于完整可行解空间边界。

**文件**: `07_multi_scenario.tex:134`

**新增**: `图中散点来自PSO搜索轨迹（50粒子×80代），反映的是PSO在当前权重下实际访问的解集分布，而非目标空间的全量均匀采样。因此该经验前沿面代表PSO搜索过程中较优解的权衡特征，不可等同于完整的可行目标空间边界。`
