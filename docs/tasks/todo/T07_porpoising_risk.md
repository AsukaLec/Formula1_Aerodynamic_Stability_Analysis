# T07: Porpoising 风险可解释性

**优先级**: 🟡 推荐 (直接对应开题报告"海豚跳"痛点)

**依赖**: T03 (代理模型就绪)

**预计耗时**: 1-2 天

**负责模块**: `src/visualization/plot_porpoising.py`

---

## 任务描述

利用代理模型的局部梯度信息，识别参数空间中气动稳定性急剧变化的区域（即"海豚跳"高风险区），生成风险热力图并叠加 PSO 最优解分析其安全性。

---

## 分步执行

### 7.1 风险量化

定义:
```
Risk(x) = ||∇f(x)|| ≈ |∂f/∂v| + |∂f/∂α|
```

- [ ] 在 `speed_kmh × wing_angle_deg` 二维网格上计算代理模型输出的梯度
- [ ] 若模型为 NN: PyTorch autograd 直接计算梯度
- [ ] 若模型为 XGBoost: 使用局部扰动 + 数值差分近似

### 7.2 热力图生成

- [ ] 分别对 DRS=0 和 DRS=1 两种状态生成风险热力图
- [ ] 颜色深浅表示海豚跳风险高低
- [ ] 叠加 T06 中各场景 PSO 最优解的位置标注
- [ ] 分析: 最优解是否在低风险区？是否靠近高风险边界？

### 7.3 物理直觉验证

- [ ] 标出高速 + 小翼角区域 (传统认知中的易失稳区)
- [ ] 标出低速 + 大翼角区域 (传统认知中的稳定区)
- [ ] 对照领域知识，检查风险热力图是否符合物理预期
- [ ] 若不符合 → 可能模型过拟合或数据偏差，需记录分析

---

## 验收标准

- [ ] 生成 DRS=0 和 DRS=1 两组 Porpoising 风险热力图
- [ ] 图上叠加了 T06 场景最优解的位置
- [ ] 报告中有一段关于最优解安全性的分析
- [ ] (推荐) 风险分布与气动物理直觉一致
