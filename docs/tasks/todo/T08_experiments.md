# T08: 实验设计与评价

**优先级**: 🔴 核心必做

**依赖**: T04 (PSO 各版本就绪), T06 (场景定义就绪)

**负责模块**: `experiments/`

---

## 任务描述

对已实现的算法进行系统的对比实验、消融实验和鲁棒性实验，用数据证明各改进模块的有效性，为结题报告提供定量实验支撑。

---

## 分步执行

### 8.1 对比实验

| 实验组 | 方法 | 对应模块 |
|--------|------|----------|
| Baseline | 标准 PSO (固定 w) | D.1 |
| Exp-1 | 自适应 PSO | D.2 |
| Exp-2 | 风险敏感 PSO | D.3 |
| Exp-3 | 风险敏感 + 密度惩罚 | D.3 + D.4 |
| Exp-4 | 主动学习增强 PSO | E (可选) |

每组:
- [ ] 独立运行 ≥ 20 次
- [ ] 统一随机种子集合
- [ ] 记录: 收敛代数、最优 fitness、最优解方差、单次耗时

### 8.2 消融实验

| 消融项 | 操作 |
|--------|------|
| 移除 σ(x) 惩罚 | λ=0，仅用 μ(x) 为适应度 |
| 移除密度惩罚 | λ₂=0 |
| 移除自适应权重 | 换回固定 w=0.7 |
| 移除复合特征 | 回退到 5 个原始特征训练模型后重新寻优 |

每组:
- [ ] 独立运行 ≥ 10 次
- [ ] 对比消融前后的性能差异

### 8.3 鲁棒性实验 (推荐)

- [ ] 不同随机种子 (≥5 种): 观察最优解一致性
- [ ] 模型输出加噪声: N(0, 0.01*σ_model)，观察 PSO 解稳定性
- [ ] 初始化扰动: 改变粒子初始位置，观察收敛结果
- [ ] PSO 超参数灵敏度: c₁/c₂/N/λ 在 ±20% 范围内扰动

### 8.4 与开题报告对照组的比较

- [ ] 实现: 多元线性回归 + 梯度搜索寻优 (作为传统方法基线)
- [ ] 对比: PSO-BP 融合模型 vs 线性+梯度法
- [ ] 对比指标: 最优解质量、收敛速度、稳定性

---

## 验收标准

- [ ] 对比实验每组 ≥ 20 次独立运行
- [ ] 消融实验每组 ≥ 10 次独立运行
- [ ] 生成收敛曲线对比图、最优解箱线图
- [ ] 生成 `reports/experiment_results.md` 含完整表格和分析
- [ ] 能定量回答: "哪个改进模块贡献最大?"

## 输入
- `src/optimization/pso_*.py` (各 PSO 版本)
- `src/scenarios/scenario_def.py`

## 输出
```
reports/experiment_results.md
figures/pso/
├── convergence_comparison.png

```

## 弹性空间

> - 若 T04 中仅实现了标准+自适应 PSO，则对比实验仅含 Baseline 和 Exp-1
> - 鲁棒性实验为推荐项，核心完成对比+消融即可
> - 若运行 20 次计算量过大，可先做 10 次快速判断稳定性，确认无异常后补足 20 次
> - 与开题报告对照组的对比为加分项，可根据需要决定是否实现
