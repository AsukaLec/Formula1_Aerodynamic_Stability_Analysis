# T05: 主动学习迭代精炼

**优先级**: 🟢 可选 (创新加分项)

**依赖**: T03 (代理模型 + DeepEnsemble), T04 (风险敏感 PSO 可运行)

**负责模块**: `src/optimization/active_learning.py`

---

## 任务描述

在 PSO 寻优过程中，利用不确定性估计识别代理模型不可信的区域，针对性增补数据并增量训练代理模型，形成 "PSO 探索 → 不确定性反馈 → 模型精炼 → 更准确的寻优" 闭环。

---

## 分步执行

### 5.1 浅层方案 (一轮迭代)

- [ ] PSO 运行完毕后，收集搜索过程中 σ(x) 最高的 Top-K 候选点
- [ ] 从原始数据集中查找这些点的最近邻真实样本
- [ ] 将最近邻样本加入训练集，重新训练一次代理模型
- [ ] 对比精炼前后模型在测试集上的指标变化

### 5.2 中层方案 (多轮迭代)

- [ ] 每 N 代 PSO 迭代后 (N=10)，触发一次主动学习
- [ ] 选择 σ(x) 大且 μ(x) 高的候选点（不确定性高但有潜力）
- [ ] 增量更新代理模型 (fine-tune 而非从头训练)
- [ ] 记录每轮精炼后的模型精度和 PSO 收敛行为变化

### 5.3 深层方案 (可选)

- [ ] 使用 Expected Improvement (EI) 或 Upper Confidence Bound (UCB) 采集函数
- [ ] 将采集函数作为粒子初始化偏置，引导 PSO 优先探索高信息增益区域

---

## 验收标准

- [ ] 至少实现浅层方案，并有精炼前后模型精度对比
- [ ] 若实现中层方案: 展示 PSO 收敛曲线在精炼前后的变化
- [ ] 报告中能清晰描述主动学习闭环的工作机制
