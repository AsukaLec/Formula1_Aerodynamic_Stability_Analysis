# 方案文档

## 总体技术路线

```text
数据预处理 (T01)
    ↓
探索性数据分析 (T02)
    ↓
多模型代理模型对比 (T03) → 选定最优模型 + DeepEnsemble
    ↓                                    ↓
风险敏感 PSO 寻优 (T04) ←── 主动学习迭代精炼 (T05, 可选)
    ↓
多场景优化 + 可解释性 (T06)
    ↓
Porpoising 风险热力图 (T07, 可选)
    ↓
对比/消融/鲁棒性实验 (T08)
    ↓
可视化汇总 (T09) → 结题报告 (T10)
```

## 创新主线

```
DeepEnsemble 不确定性估计
    → 风险敏感 PSO (Fitness = μ - λσ)
    → 主动学习闭环 (可选)
    → Porpoising 风险可解释性
    → 多场景决策可解释性体系
```

|---|--------|------|------|

## 任务依赖图

```
T01 ──→ T02 ──→ T03 ──→ T04 ──→ T06 ──→ T08 ──→ T09 ──→ T10
                     │       │
                     │       └──→ T05 (可选, 依赖 T03+T04)
```

## 推荐执行顺序

按任务依赖关系，建议顺序执行：

```
T01 → T02 → T03 → T04 → T06 → T08 → T09 → T10
                ↘ T07 (可与 T04/T06 并行)
                     T05 (在 T04 可用后开始)
```

---

## 弹性策略

- **核心路径**: T01 → T02 → T03(XGBoost后备) → T04(标准+自适应) → T06(S1+S2) → T08(对比+消融) → T09 → T10
- **加分路径**: 核心路径 + T04(风险敏感) + T06(SHAP+灵敏度) + T07(Porpoising)
- **满分路径**: 加分路径 + T05(主动学习) + T06(反事实+决策规则)

---

## 风险预案

| 风险 | 应对 |
|------|------|
| NN 模型精度不足 | 回退到 XGBoost → Random Forest |
| DeepEnsemble 耗时过长 | 降级 MC-Dropout 或单模型 + 密度惩罚 |
| PSO 收敛不稳定 | 增加运行次数、调参、引入重启机制 |
