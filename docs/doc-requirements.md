## 1. 问题定义

2022 年 FIA 引入"地面效应"规则后，F1 赛车气动设计面临核心矛盾：

1. **规则约束**: 体育规则对 CFD 仿真时长及计算资源实施严格配额 (ATR)，传统高精度仿真在有限周期内难以覆盖大规模参数空间
2. **瞬态非线性**: "海豚跳" (Porpoising) 涉及多参数共振，传统方法难以捕捉其强耦合非线性特性
3. **数据不平衡**: 数据集中高稳定性样本占绝对多数，低稳定性样本稀缺

本课题旨在构建一套 **数据驱动的代理模型 + 智能优化** 框架，降低对 CFD 仿真依赖，实现不同工况下最优气动参数的快速求解。

## 2. 数据

### 来源
[Kaggle - F1 Aerodynamic Stability and Porpoising (150k Samples)](https://www.kaggle.com/datasets/igormerlinicomposer/f1-aerodynamic-stability-and-porpoising-150k-samp/data)

### 结构
| 字段 | 类型 | 描述 |
|------|------|------|
| `speed_kmh` | float64 | 时速 |
| `wing_angle_deg` | float64 | 前翼角度 |
| `drs_active` | int (0/1) | DRS 状态 |
| `downforce_n` | float64 | 下压力 |
| `drag_n` | float64 | 阻力 |
| `stability_index` | float64 | 稳定性 (0-100, 越大越好) |

### 特点
- ~150k 样本
- 高稳定性 (≥95) 样本占优
- drs_active 为二值特征
- 多变量间存在高度非线性关系

---

## 3. 核心需求

### F1: 代理模型构建
- 建立从 5 个输入到 stability_index 的回归模型
- 预测精度: R² ≥ 0.85 (最低), ≥ 0.92 (理想)
- 推理速度: 适合 PSO 高频调用 (单次 ≤ 10ms)
- 需对比 ≥ 4 种模型

### F2: PSO 参数寻优
- 在参数约束空间内搜索最大化 stability_index 的参数组合
- 需解决数据不平衡导致的搜索偏置
- 需防止 OOD 搜索 (代理模型幻觉)

### F3: 多场景优化
- 定义 ≥ 2 组典型 F1 赛道工况
- 各场景在特定约束下输出最优参数组合

### F4: 可解释性
- 最优解决策归因 (SHAP)
- 多场景参数倾向差异
- Porpoising 风险区域识别

## 4. 量化目标

| 指标 | 最低达标 | 理想目标 |
|------|----------|----------|
| R² | ≥ 0.85 | ≥ 0.92 |
| MSE | ≤ 0.05 | ≤ 0.02 |
| PSO 收敛代数 | ≤ 80 | ≤ 50 |
| 最优解标准差 (20 次) | ≤ 0.05 | ≤ 0.02 |
| 单次寻优耗时 | ≤ 20s | ≤ 5s |
