### Slide 11 — PSO 算法

**布局**: 左侧公式+配置 55%，右侧放 `05_pso_convergence.png` 45%

**标题**: `08  粒子群优化算法`

**左侧文本**:
```
标准 PSO:
  v_i^{t+1} = w·v_i^t + c₁r₁(p_i - x_i^t) + c₂r₂(g - x_i^t)
  x_i^{t+1} = x_i^t + v_i^{t+1}

自适应惯性权重:
  w(t) = 0.9 - (0.9-0.4) × t/Tmax
  早期 w 大 → 全局探索
  后期 w 小 → 局部精细搜索

PSO 配置:
  粒子数 N=50, 最大迭代 80
  c₁=2.0, c₂=1.5
  λ=1.0 (中等风险厌恶)
  收敛判定: stall ≥ 12 代即终止
  单次寻优耗时: 72ms
```

**右侧**: `05_pso_convergence.png`

**讲解要点**:
- "经典 PSO 公式, 粒子在位置空间和速度空间中迭代"
- "我们的改进: 惯性权重从 0.9 线性递减到 0.4——先探索后利用"

### Slide 12 — 不确定性感知改进 (核心改进)

**标题**: `09  不确定性感知的风险敏感适应度`

**左侧文本**:
```
核心公式:
  Fitness(x) = μ(x) - λ·σ(x) - P_scenario(x)

同时解决三个问题:
  ① OOD 防护: σ(x) 在分布外增大 → 惩罚使粒子返回可靠区
  ② 不平衡缓解: 低稳定性区 σ(x) 更高 → 避免追求名义高分
  ③ 幻觉抑制: λ=0 → 适应度 101.30 (超理论上限 100!)
               λ=1 → 适应度 99.83 (物理合理)

与贝叶斯优化 LCB 的区别:
  本方法将不确定性惩罚直接嵌入 PSO 优化目标函数
  而非作用于采样策略 — 面向可靠性, 非探索-利用平衡

方法论定位:
  将不确定性感知思想引入 PSO 群体智能框架
  非提出全新优化范型
```

**右侧**: `lambda_vs_stability.png`

**讲解要点**:
- "这就是我们的核心改进——在 PSO 的适应度函数里减去 λ·σ(x)"

- "注意定位: 我们不是 '发明了一种新算法', 而是 '把不确定性感知引入了 PSO'"
