\section{代理模型构建}

\subsection{候选模型谱系}

为建立赛车工况参数到稳定性评分的回归映射，
从传统回归到深度学习构建了6个模型的完整对比谱系：

\begin{enumerate}
    \item \textbf{M1 Ridge}（Ridge回归）：线性基准模型，
        提供模型复杂度下界的参考；
    \item \textbf{M2 Random Forest}（随机森林）：集成学习的经典代表，
        对噪声和过拟合有一定鲁棒性；
    \item \textbf{M3 XGBoost}：梯度提升决策树，
        以其在表格数据上的卓越表现著称；
    \item \textbf{M4 MLP}（多层感知机）：3隐藏层（128-256-128-64）
        的前馈神经网络，配备ReLU激活和Dropout正则化；
    \item \textbf{M5 TabNet}：基于注意力机制的可解释深度学习模型，
        专为表格数据设计；
    \item \textbf{M6 DeepEnsemble}（深度集成）：3个独立MLP的集成，
        仅改变初始化种子和数据shuffle。
        输出预测均值$\mu(x)$和标准差$\sigma(x)$，
        为风险敏感PSO提供不确定性估计。
\end{enumerate}

\subsection{训练配置}

MLP/DeepEnsemble采用以下训练配置：
\begin{itemize}
    \item 优化器：Adam（lr=$1\times10^{-3}$，weight\_decay=$1\times10^{-5}$）
    \item 损失函数：加权MSE（低稳定性样本权重加倍）
    \item 正则化：Dropout（p=0.2），Early Stopping（patience=20）
    \item 批量大小：256
    \item 最大训练轮数：500
\end{itemize}

为应对数据不平衡问题，
在损失函数中引入类平衡权重，
使模型对低稳定性样本的预测误差给予更高惩罚。

XGBoost采用以下配置：
\begin{itemize}
    \item 树数量：300
    \item 最大深度：6
    \item 学习率：0.1
    \item 子采样率：0.8
    \item 列采样率：0.8
\end{itemize}

\subsection{评价指标}

采用以下指标评估各模型性能：

\begin{equation}
    \text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
    \label{eq:mse}
\end{equation}

\begin{equation}
    R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}
                    {\sum_{i=1}^{n}(y_i - \bar{y})^2}
    \label{eq:r2}
\end{equation}

\begin{equation}
    \text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|
    \label{eq:mae}
\end{equation}

\subsection{模型选择策略}

基于精度-效率权衡：
\begin{itemize}
    \item \textbf{可解释性分析}（SHAP、排列重要性）：
        使用XGBoost（M3），
        因其TreeExplainer精确快速；
    \item \textbf{PSO寻优}：使用DeepEnsemble（M6），
        以提供$\mu(x)$和$\sigma(x)$用于风险敏感适应度计算。
\end{itemize}

\subsection{数据集来源与模型精度可信性论证}

代理模型R$^2$接近1.0的结果初看异常，
但经追溯数据集来源可得到合理解释。
本课题使用的数据集
\href{https://www.kaggle.com/datasets/igormerlinicomposer/f1-aerodynamic-stability-and-porpoising-150k-samp/data}{F1 Aerodynamic Stability and Porpoising}
由\textbf{XGBoost预测引擎}在NVIDIA P100 GPU上生成，
生成器本身验证精度达99.66\%。
数据集本质上是XGBoost引擎对气动物理模型的\textbf{数值近似输出}，
而非真实CFD仿真结果。

由于代理模型（XGBoost/M3）与数据生成器共享相同的模型架构和归纳偏置，
模型能够以极高精度复现生成规则是\textbf{数学上可预期的}。
Random Forest的$R^2=1.0000$和XGBoost的$R^2=0.9999$
反映的是模型成功学习了数据的内在结构，
而非过拟合或数据泄露。
值得注意的是，Random Forest达到近乎完美精度（$R^2=1.0000$, $MSE\approx 0$）
表明该数据生成机制具有较强的结构规律性——
即便采用与生成器（XGBoost）不同的模型架构（RF基于Bagging和随机子空间），
只要模型容量足够，即可近乎零误差地复现生成规则。
这进一步说明代理模型性能已接近该数据集可达到的信息上限，
不同模型架构之间的性能差异在此数据分布下已被压缩至极小。

需要指出，由于数据生成器和被测模型（M3 XGBoost）同属XGBoost架构，
XGBoost在模型对比中的优势部分受益于与数据生成器共享的归纳偏置。
因此，本实验的代理模型对比结果更多反映
不同模型对该数据生成机制的逼近能力，
而非其在真实CFD场景下的绝对性能优劣。
在真实工程场景中，代理模型的性能上限取决于
训练数据的物理保真度，而非模型复杂度的无限提升。

为独立验证模型的泛化能力，

不能排除数据生成器本身的系统性偏置（XGBoost引擎同源问题）
或共享归纳偏置导致的模型结构优势。

\subsection{研究路线调整说明}

本课题开题阶段确定的技术路线为"BP神经网络作为代理模型+PSO进行优化"。
研究过程中，实验证据促使路线发生如下自然演化：

\begin{enumerate}
    \item \textbf{BP神经网络实验效果一般}：
        MLP（M4）的R$^2=0.9994$虽已达标，
        但其MSE（0.3897）约为XGBoost的12.5倍，
        且推理延迟（0.403ms）在PSO高频调用场景下仍非最优；

    \item \textbf{XGBoost显著更优}：
        XGBoost在所有指标（R$^2=0.9999$, MSE=0.0312, 延迟0.242ms）
        上均大幅领先，且其TreeExplainer为后续SHAP可解释性分析提供了原生的精确支持；

    \item \textbf{DeepEnsemble提供不确定性}：
        XGBoost虽精度最高，但无法提供预测不确定度$\sigma(x)$。
        DeepEnsemble通过3个独立MLP的集成输出$\mu(x)$和$\sigma(x)$，
        为风险敏感PSO提供了\textbf{关键的UFI（不确定性感知）能力}，
        这是单模型（包括XGBoost）所不具备的。
\end{enumerate}

因此，最终技术路线调整为：
\textbf{XGBoost}负责可解释性分析（SHAP、排列重要性），
\textbf{DeepEnsemble}负责PSO寻优（提供$\mu(x)$和$\sigma(x)$）。
BP神经网络作为M4保留在对比谱系中，
其角色从"主要工具"转变为"基准线参考之一"。
这一调整体现了数据驱动研究的实事求是原则——
代理模型的选择应由实验证据而非预先假设决定。
